# Источники логотипов TruckIQ

Дата получения: 2026-10-25. Изображения скачаны без перерисовки и изменения цвета из [Car Logos Dataset](https://github.com/filippofilip95/car-logos-dataset), архивирующего Carlogos.org. Это архивные изображения реальных знаков, а не утверждение об актуальности брендбука. Проверены визуально, PNG декодируются, содержат прозрачные пиксели. Общие знаки Volvo и Mercedes-Benz показаны с точными подписями грузовых марок; отдельный Renault Trucks не заменён логотипом легковых Renault.

Лицензия MIT репозитория не распространяет свободную лицензию на товарные знаки: права остаются у владельцев. TruckIQ не заявляет партнёрство с производителями.

## Референс truckmsk.ru

Сайт только запрашивался на чтение. Веб-инструмент: URL is not accessible. HTTP из среды: CONNECT tunnel failed, response 403. Chromium: net::ERR_TUNNEL_CONNECTION_FAILED. Визуальное расположение и изображения блока недоступны; текущая сетка — самостоятельная реализация в согласованном стиле TruckIQ, без заявления о точном воспроизведении TRUCKMSK.

## Переработка современных изображений — 2026-10-25

Изменения: старые объёмные PNG MAN, Iveco, Hyundai заменены неизменёнными плоскими SVG из `simple-icons@16.35.0` (получен через npm). Геометрия SVG и исходный чёрный цвет сохранены; не выполнялись перерисовка или самостоятельное построение товарных знаков. Это более чистые векторные изображения из текущего выпуска коллекции, но дата пакета сама по себе не доказывает соответствие последнему брендбуку.
