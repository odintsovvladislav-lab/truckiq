## Выбранный дизайн TruckIQ

По решению владельца основной интерфейс использует оформление «ТракПомощи»: Days для заголовков, Stem для текста, синий #0a2945, оранжевый #f28b16, белый фон и светлые карточки с оранжевой верхней линией. Шрифты размещены локально. Основной вариант открывается по `/`; прежняя галерея — по `/?concept=gallery`, пять концепций — по `/?concept=1` … `5`.

Изменение касается оформления. Реальная диагностическая база пока не подключена. Публикация и слияние в main не выполнялись.

# TruckIQ — пять концепций интерфейса

Локальная галерея пяти самостоятельных дизайнов русскоязычного помощника по грузовикам. Финальная концепция и корпоративный шрифт **не выбраны**. Только UI-прототип: без реальных диагностических данных, ремонтных инструкций и вымышленных расшифровок.

## Запуск

Node.js 22.12+; проверено на Node 24.19.

```sh
npm ci --cache /tmp/truckiq-npm
npm run dev
```

Открыть http://localhost:5173/ — галерея. `npm run build && npm run preview` — локальный просмотр production-сборки.

| Адрес | Концепция | Композиция | Типографика |
|---|---|---|---|
| `/?concept=1` | Фокус | Центрированный поиск, минималистичная главная без отвлекающего изображения | Onest |
| `/?concept=2` | Мастерская | Боковая навигация, компактный поиск, небольшое изображение, белая рабочая панель | IBM Plex Sans |
| `/?concept=3` | Перспектива | Editorial: крупный заголовок с засечками, отдельный визуал и контрастная поисковая полоса | PT Serif + Golos Text |
| `/?concept=4` | Каталог | Крупные карточки, региональные колонки, каталог как основной способ входа | Manrope |
| `/?concept=5` | Контур | Тёмно-синяя техническая среда, контрастный поиск и светлые карточки | IBM Plex Sans |
| `/?concept=original` | Прежняя версия | Сохранённый дизайн перед редизайном | Roboto |
| `/comparison.html` | Лист сравнения | Пять экранов при одинаковом viewport 1440 × 1000 | — |

Переключатель концепций расположен над прототипом; «Все концепции» возвращает в галерею. Общие маршруты используют hash: `#brands`, `#schemes`, `#repair`, `#favorites`, `#search`, `#brand%2FScania`. Пять концепций используют одну реализацию поиска, фильтров, навигации и избранного. Прежняя версия сохранена в src/previous.ts и src/previous.css.

## Что работает

- Поиск по коду или симптому с валидацией пустого ввода и честным результатом «база не подключена».
- Все 20 марок: 7 европейских и 13 азиатских. Изображения логотипов сохранены во всех пяти дизайнах.
- Фильтры региона/названия, сброс и пустое состояние; карточки марок и переходы всех 20 логотипов.
- Избранное в localStorage, удаление, счётчик и сохранение после перезагрузки.
- Разделы схем/ремонта только демонстрационные. Обработка неизвестных маршрутов, мобильное меню, состояния фокуса.
- Удалённый блок «Одна платформа» отсутствует во всех версиях.

## Шрифты и изображения

Все шрифты локальные из @fontsource, подключены реальные Latin/Cyrillic файлы и веса 400/500/700 (PT Serif: 400/700). Фактическая загрузка семейств проверена в браузере. Лицензии находятся в public/licenses. Шрифты различаются намеренно по концепциям; это не новый окончательный выбор корпоративной типографики.

16 настоящих логотипов; для Renault Trucks, Sitrak, Howo и Mitsubishi Fuso остаются честные текстовые карточки. Никакие чужие знаки вместо них не подставляются. Источники, контрольные суммы, проверки официальных сайтов и ограничения актуальности: LOGO_SOURCES.md. В этом редизайне сами знаки не изменялись.

Изображение public/images/truck-diagnostics.png сгенерировано встроенным image_gen: тягач и диагностический планшет с пустым экраном, без чужих логотипов. Это AI-иллюстрация с соответствующей подписью, не документальное фото. Используется во 2, 3, 5 концепциях; в минималистичной и каталожной композициях убрано с главной. Растр программно не редактировался.

## Проверки

```sh
npm run build
npm run lint
npm test
```

14 Playwright-тестов прошли: 5 концепций × desktop/mobile, прежняя версия × 2, галерея × 2. Проверены загрузка шрифтов и 16 изображений, 20 переходов в каждом концепте, поиск/пустой ввод/повторные клики, безопасное отображение ввода, фильтры 20/7/13 и сброс, избранное и перезагрузка, мобильное меню, пустые разделы, неизвестная страница, отсутствие горизонтального переполнения на 320/390/768/1440 px, отсутствие JS-ошибок. Build, lint и git diff --check успешны. Все пять десктопных и мобильных экранов сравнены визуально рядом. На физических устройствах и Safari/Firefox не проверялось.

Playwright использует `/usr/bin/chromium`, если он установлен. Иначе требуется `npx playwright install chromium`. В данной среде загрузка браузера с CDN блокировалась 403; тесты прошли на установленном Chromium.
